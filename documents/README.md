# documents — 저장소의 문서 전부

**2026-10-21 정리.** 루트에 흩어져 있던 문서 폴더 다섯 개(`문서/` · `docs/` · `meeting/` · `reports/` · `_archive/`)를
이 폴더 하나로 묶고, 안을 문서 성격으로 나눴다. **지운 문서는 없다** — 자리만 옮겼다.

처음 보는 사람은 [`현황/현재상황_읽기순서.txt`](현황/현재상황_읽기순서.txt) 부터.

`보관/` 과 `옛판/` 은 **뜻이 다르다.** 보관은 그때 확정된 판이고, 옛판은 같은 문서의 고치기 전 판이다.

**`작업보고/` · `보관/` · `옛판/` 의 본문은 고치지 않는다** — 그 시점의 기록이다. 그래서 그 안에는
옛 경로(`reports/…` · `문서/…` · `_archive/…`)가 그대로 적혀 있다. 아래 표로 찾아간다.

## 옛 경로 → 새 경로

| 옛 경로 | 새 경로 |
|---|---|
| `문서/` (맨 위 파일) | 성격에 따라 `요구사항/` · `규약/` · `협의/` · `가이드/` · `현황/` · `작업프롬프트/` |
| `문서/REPORT_bridge.md` | `작업보고/REPORT_bridge.md` |
| `문서/KCI/` | `논문/` |
| `문서/보관/` | `보관/` |
| `문서/260922 회신/` · `문서/시각화 인계문서_260921/` | `협의/` 아래 같은 이름 |
| `docs/interfaces/` | `규약/` |
| `docs/research/` · `docs/다이어그램_원본_mermaid.md` | `참고/` |
| `docs/verify_docs.py` | `verify_docs.py` (이 폴더 맨 위) |
| `meeting/` | `회의록/` |
| `reports/` | `작업보고/` |
| `_archive/` | `옛판/` |

현행 문서와 코드 주석이 가리키던 경로는 옮기면서 새 경로로 같이 고쳤다.

## 검사

```
python documents/verify_docs.py
```

저장소 루트에서 실행한다. 읽기 순서가 가리키는 문서가 있는지, 본문이 가리키는 경로 · 요구사항 ID · npm 스크립트가 실제로 있는지 본다.
