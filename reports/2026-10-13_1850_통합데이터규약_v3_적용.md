### 5. 정할 것 — 내가 정하지 않았다

**가. `normalize_stream_jsonl.py` 의 출력 이름 (⑩ⓑ)**

- 이 도구는 원본은 그대로 두고 **이름을 맞춘 사본(`*.std.jsonl`)** 을 만든다. 맞추는 기준이 **10-06 이름사전**이다. v3 는 v1안 · 질문답변 · v2 를 대신한다고 적었고, 이름사전은 그보다 앞이다.
- v2 와 반대인 출력: `sequence_id` → `seq`(253행) · `battery_pct` → `battery.pct`(282행 — v2 는 거꾸로 `battery.pct` 를 지운다) · 드론 `remaining_pct` → `pct`(287행) · `origin` 통째 → `device_info`(308행 — v2 는 3칸) · `gps.fix` 지움(303행 — v2 P3-1 은 둔다) · `flight.age_s` 지움(295행) · `timestamp` → `sent_at` 이동 · `frame_ref{camera_id, seq, timestamp}` · 기록 `source`·`edge_received_at` · 결과 `process_lag_ms`·`hfov_deg`·`hfov_given_deg`.
- (1) 규약 문구대로 **읽기만** 고친다 — 사본 이름은 10-06 그대로. 손이 덜 가지만 v2 원본과 std 사본의 이름이 다르다.
- (2) **출력도 v2 모양으로** 맞춘다 — 이 도구가 「옛 기록 → v2 모양 변환기」가 되고 v2 기록은 거의 그대로 지나간다. 출력에 `check_v2.py` 를 돌려 검증할 수 있다. 출력 부분을 다시 써야 한다.

**나. BE-03 v2 media-header 의 공통 머리 (⑫)** — `message.schema.json` 의 칸을 `$ref` 한다(⑫ 시험이 그대로 성립) / 같은 정의를 둔다(⑫ 시험을 v1 복사본 기준으로 고친다).

**다. DS-06 에서 결과를 쓰는 자리에 그 장의 기록을 넘기는 방법 (⑥)** — `ModelOutput.write(…, header=…)` 인자를 더한다 / `base["_frame_header"] = header` 로 실어 둔다(밑줄로 시작하는 칸은 `v2_record` 가 버린다).

**라. `frame_file` 의 기준 (⑧)** — 규약 정정이라 BE(문서 관리자)가 정한다. 값은 그대로 두고 규약에 기준을 적는다 / 결과 쪽도 저장 폴더 기준으로 바꾼다(이어 하기 `done` 집합과 오버레이 파일 이름이 같이 바뀐다).

**나 — `$ref` 가 뒤에 문제가 덜 생기는 이유**

- 정의가 한 곳에 있다. 공통 머리 칸의 형식이 `message.schema.json` 에서 바뀌면 프레임 헤더도 같이 바뀐다. 같은 정의를 두 곳에 적으면 한쪽만 고치는 일이 생긴다.
- 지금 미디어 헤더가 `frame_ref` 를 `frame-reference.schema.json` 에서 `$ref` 로 가져오는 방식과 같다. 레지스트리(`backend/ingest/envelope.py` `build_registry`)가 이미 `contracts/common/` 의 규격 전부를 올리므로 따로 할 일이 없다.
- `message.schema.json` 의 일곱 칸 정의(`schema_version` 정규식 · `source_id`·`node_id`·`zone_id`·`session_id` 글자 `minLength: 1` · `timestamp` date-time · `sequence_id` 0 이상 정수)는 프레임 헤더에 그대로 맞는다.
- 칸 단위 `$ref`(`message.schema.json#/properties/<칸>`)가 풀리는지 jsonschema 4.26 + referencing 으로 시험했다 — 레지스트리에 두 규격이 다 있으면 양성 통과 · 음성(`sequence_id: -1`) 거부, `message.schema.json` 이 레지스트리에 없으면 참조 오류로 실패한다. 그래서 발견 ⑫ 의 시험(`test_unregistered_ref_fails_without_network`)이 고치지 않고 그대로 성립한다.
- 메시지 규격 전체를 `allOf` 로 가져오지 않는다 — 프레임 헤더에서 지운 `correlation_id` 같은 칸 정의까지 딸려 온다.
